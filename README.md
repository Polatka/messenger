# Polatka 0.4 — Windows x64

## Запуск

Закройте старую Polatka. Если скачан полный ZIP, распакуйте его целиком в отдельную папку и запустите Polatka.exe. EXE нельзя переносить отдельно от resources и остальных файлов. Node.js не нужен. Профиль и история предыдущей версии сохраняются в прежнем профиле приложения.

## Что изменилось

1. Окна подключения, настроек, записи, выбора экрана и громкости теперь используют выбранный цвет. Он сохраняется после перезапуска.
2. Громкость собеседника 0–200% открывается только с его аватара на экране активного звонка. Аватары чата и списка участников больше не открывают регулятор. Раздел звонка показывает название созданного или принятого лобби.
3. При запуске — короткая анимация исходного логотипа. При системной настройке уменьшения движения заставка отключается.
4. Профиль: имя, описание, загрузка/удаление фото JPG, PNG или WebP до 5 МБ. Фото обрезается по центру в квадрат и уменьшается для передачи собеседнику. Имя и описание сохраняются кнопкой «Сохранить», фото применяется сразу.
5. Передача файлов в чате по кнопке со скрепкой. Максимум 25 МБ на файл. Получатель нажимает «Принять» или «Отклонить». Есть прогресс и отмена. После получения доступно «Сохранить файл» с выбором папки; вложения автоматически не открываются.
6. Голосовое сообщение: кнопка микрофона рядом с полем ввода → «Записать» → «Остановить» → прослушать → «Отправить». До 5 минут и 12 МБ.
7. Видеокружок: круглая кнопка воспроизведения рядом с полем ввода. До 60 секунд и 12 МБ. После остановки доступен предпросмотр. На экране чата видео показывается в круге; сохранённый файл содержит исходный кадр камеры.
8. Громкость кликов 0–100% и кнопка прослушивания в настройках. 0% или выключатель отключают звуки. Это не меняет громкость собеседника.

## Передача и хранение

Для файлов, фото профиля и записей рекомендуется Polatka 0.4 у обоих участников. Для вложений это обязательно: старая версия не поддерживает новый протокол, и кнопки не активируются. Лобби пока на двоих. Одновременно можно отправлять один файл и принимать один файл. Закрытие соединения отменяет незавершённую передачу; автоматического возобновления нет. По окончании сверяется SHA-256.

Запись сообщения доступна вне активного звонка; камера и микрофон включаются только после «Записать» и останавливаются после завершения/отмены. Без отдельной кнопки «Отправить» запись не передаётся. При выборе устройств используются сохранённые настройки микрофона и камеры.

Файлы и записи передаются напрямую через соединение WebRTC и кэшируются на устройстве в IndexedDB. Кэш ограничен 150 МБ; старые вложения удаляются из кэша первыми, а их запись в истории остаётся. Нужные файлы сохраните в свою папку. При нехватке места появляется сообщение об ошибке сохранения. Текстовая история хранит последние 300 сообщений лобби. Облачного хранилища и доставки офлайн нет.

## Подключение лобби

Создатель выбирает название, создаёт приглашение и отправляет код другу. Друг вставляет код, подготавливает ответ и передаёт его создателю. Создатель вставляет ответ и нажимает «Соединиться».

В этой сборке по-прежнему используется ручной обмен кодами и STUN. Автоматический облачный сигналинг и TURN пока не подключены; на некоторых сетях прямое соединение не установится. Само приложение не требует Radmin, но без TURN не гарантирует соединение через любые NAT. Встроенного VPN нет. Запрос демонстрации 1080p/60 — целевые параметры, а не гарантия качества.

## Проверка и ограничения

Подробные результаты проверок находятся в QA.md. Запуск Windows EXE и реальное прослушивание на двух Windows-компьютерах необходимо проверить отдельно. Приложение не подписано сертификатом разработчика.

## Исходники

Source содержит проект Electron и тесты. Команды: npm ci, npm test, npm start, npm run pack:win. Для установки зависимостей нужен доступ к npm и загрузкам Electron. Интерфейс: renderer. Системная оболочка и сохранение файлов: desktop. Протокол вложений: renderer/transfer.js. Запись, профиль и UI вложений: renderer/features.js.
