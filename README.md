# Polatka 0.4.1 — Windows x64

## Запуск

Закройте старую Polatka. Если скачан полный ZIP, распакуйте его целиком в отдельную папку и запустите Polatka.exe. EXE нельзя переносить отдельно от resources и остальных файлов. Node.js не нужен. Профиль и история предыдущей версии сохраняются в прежнем профиле приложения.

## Что изменилось в 0.4.1

- Звук звонка: удалённый трек подключается к элементу воспроизведения и Web Audio. При принятии звонка обработчик повторно запускает аудиоконтекст; при блокировке доступна кнопка «Включить звук». Индикатор речи считывает реальный сигнал трека. Исправлен отказ, при котором ошибки создания аудиографа скрывались и другого канала воспроизведения не было.
- Лобби: владелец создаёт приглашение и подтверждает ответ. У гостя эти действия недоступны. Роль сохраняется при перезапуске и разрыве сети. Кнопка «Выйти из лобби» возвращает гостя в новое собственное лобби. Личные кнопки звонка, камеры и микрофона доступны обоим участникам.
- Сообщения: «Удалить у меня» удаляет сообщение и локальный файл на этом устройстве. «Удалить у всех» доступно для своих новых сообщений и вложений при подключённом собеседнике с Polatka 0.4.1. Удаление отменяет передачу, останавливает воспроизведение и очищает локальный кэш. Полученные файлы, отдельно сохранённые на диск, остаются в выбранной папке. Старые текстовые сообщения можно удалить только у себя. Синхронизации удаления офлайн нет.
- Микрофон: усиление 0–300% в настройках. 100% — обычный уровень, 0% — тишина. Применяется сразу к звонку и проверке; новые голосовые сообщения и видеокружки используют тот же уровень. Лимитер сглаживает перегрузку. При искажениях уменьшите усиление.
- Оформление: три фона, три шрифта чата, размер текста, плотность сообщений, скругление панелей, прозрачность и анимации. Настройки видны сразу и сохраняются локально; есть сброс. Системная настройка уменьшения движения имеет приоритет.
- Новая короткая заставка: плавное появление эмблемы, расходящиеся кольца и световая полоса. Эмблема с прозрачным фоном используется на заставке, в боковой панели и в заголовке окна.

### Переход с 0.4.0

Обновиться желательно обоим участникам. Профиль и история остаются в прежнем хранилище. В 0.4.0 роль владельца не сохранялась, поэтому старое лобби после первого запуска считается гостевым. Нажмите его название → «Выйти из лобби», чтобы создать своё приглашение. Старая история остаётся в локальном хранилище.

Лобби остаётся прямым соединением двух устройств. Права проверяются интерфейсом и обработчиками приложения; серверных команд управления, аккаунтов и централизованного управления участниками в этой версии нет.

## Передача и хранение

Для файлов, фото профиля и записей рекомендуется Polatka 0.4 у обоих участников. Для вложений это обязательно: старая версия не поддерживает новый протокол, и кнопки не активируются. Лобби пока на двоих. Одновременно можно отправлять один файл и принимать один файл. Закрытие соединения отменяет незавершённую передачу; автоматического возобновления нет. По окончании сверяется SHA-256.

Запись сообщения доступна вне активного звонка; камера и микрофон включаются только после «Записать» и останавливаются после завершения/отмены. Без отдельной кнопки «Отправить» запись не передаётся. При выборе устройств используются сохранённые настройки микрофона и камеры.

Файлы и записи передаются напрямую через соединение WebRTC и кэшируются на устройстве в IndexedDB. Кэш ограничен 150 МБ; старые вложения удаляются из кэша первыми, а их запись в истории остаётся. Нужные файлы сохраните в свою папку. При нехватке места появляется сообщение об ошибке сохранения. Текстовая история хранит последние 300 сообщений лобби. Облачного хранилища и доставки офлайн нет.

## Подключение лобби

Создатель выбирает название, создаёт приглашение и отправляет код другу. Друг вставляет код, подготавливает ответ и передаёт его создателю. Создатель вставляет ответ и нажимает «Соединиться».

В этой сборке по-прежнему используется ручной обмен кодами и STUN. Автоматический облачный сигналинг и TURN пока не подключены; на некоторых сетях прямое соединение не установится. Само приложение не требует Radmin, но без TURN не гарантирует соединение через любые NAT. Встроенного VPN нет. Запрос демонстрации 1080p/60 — целевые параметры, а не гарантия качества.

## Проверка и ограничения

Подробные результаты проверок находятся в QA.md. Изменения аудиотракта проверены модульными тестами и синтетическим сигналом. Запуск Windows EXE и реальное прослушивание на двух Windows-компьютерах необходимо проверить отдельно. Приложение не подписано сертификатом разработчика.

## Исходники

Архив исходников содержит проект Electron и тесты. Команды: `npm ci`, `npm test`, `npm start`, `npm run pack:win`. Проверки браузера: `npm run test:ui` и `npm run test:audio-browser` (нужны Playwright и Chromium; пути можно указать через `PLAYWRIGHT_MODULE` и `CHROMIUM_EXECUTABLE`). Для установки зависимостей нужен доступ к npm и загрузкам Electron. Интерфейс: renderer. Системная оболочка и сохранение файлов: desktop. Протокол вложений: renderer/transfer.js. Запись, профиль и UI вложений: renderer/features.js.
